Descrição
BlueRed é uma página de entrada (project launcher) que centraliza e apresenta os projetos desenvolvidos no âmbito da unidade curricular de Edições Multimédia Interativas da Licenciatura em Engenharia Multimédia do ISTEC Porto.
A interface combina uma estética gótica e extravagante com navegação responsiva, permitindo ao utilizador aceder rapidamente a cada um dos projetos multimédia disponíveis.

Funcionalidades

Apresentação visual de todos os projetos do portfólio
Navegação direta para cada aplicação interativa
Design responsivo adaptado a dispositivos móveis e desktop
Estética gótica consistente com o tema do portfólio


Tecnologias

HTML5
CSS3
JavaScript (vanilla)

bashgit clone https://github.com/markelomc-a11y/ISTEC26BlueRed.git
